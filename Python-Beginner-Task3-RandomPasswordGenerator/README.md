Project Description
This project is a simple Random Password Generator developed using Python. It generates random passwords based on the user's preferred length and selected character types.

Features
- Generates passwords with a minimum length of 8 characters.
- Supports uppercase letters.
- Supports lowercase letters.
- Supports numbers.
- Supports special symbols.
- Allows users to generate another password.
- Validates user input and displays error messages.

Technologies Used
- Python
- Random module
- String module

How to Run
1. Download the Python file.
2. Open it using Python or Google Colab.
3. Run the program.
4. Enter the desired password length.
5. Select at least two character types.
6. View your generated password.
