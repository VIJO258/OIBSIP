Task: Task 2 – BMI Calculator
Level: Beginner

Project Description
This project is a simple BMI Calculator developed using Python. It takes the user's weight and height as input, calculates BMI, and displays the corresponding category.

Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI using the BMI formula.
- Displays BMI rounded to two decimal places.
- Classifies the BMI result.
- Handles invalid and non-numeric inputs.

Technology Used
- Python 3
- Google Colab

How to Run
Run the "Aswinvijo_Task2.py" file using Python.
